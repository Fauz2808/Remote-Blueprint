# Remote Blueprint Logo System

## Konsep: Forward Blueprint

Monogram `B` custom: upper chamber mewakili blueprint/struktur, lower chamber berubah menjadi bentuk maju. Signal lime menandai transisi dari panduan ke eksekusi. Siluet warna dan monokrom sama sehingga identitas tetap terbaca tanpa warna.

## Palet

- Pine deep: `#073622`
- Blueprint paper: `#F6F6F0`
- Warm white: `#FFFDF5`
- Signal lime: `#D9F56F`
- Ink: `#172019`

## Aturan

- Avatar memakai mark tanpa teks.
- Ukuran minimum avatar: 24 px. Lockup: 220 px lebar.
- Clear space minimum: seperempat tinggi tile avatar.
- Jangan ubah proporsi, rotasi, shadow, atau warna signal lime.
- Jangan memasukkan nama/logo Upwork ke lockup permanen. Referensi platform ditempatkan di bio atau copy kampanye.
